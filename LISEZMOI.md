# Score Fléchettes

Compteur de points aux fléchettes, sans pub : https://scoreflechettes.fr

- `index.html` : l'appli (version web).
- `.github/workflows/apk.yml` : à chaque modification, fabrique l'APK Android et met le site à jour sur l'hébergement OVH (scoreflechettes.fr), APK comprise.
- `supabase.sql`, `invitations.sql` : base de données des comptes (Supabase).
- `ecran-raspberry.md` : réglage du Raspberry pour l'écran sous la cible.
